# Army Rush

Protótipo Android offline com jogabilidade 2.5D estilizada: arraste para mover, atravesse portões de soma e multiplicação, enfrente inimigos e avance de fase.

## APK
Abra **Actions → Compilar APK Android**. Após o workflow terminar com sucesso, abra a execução e baixe o artefato **ArmyRush-APK**. Extraia o ZIP e instale `app-debug.apk` no Android.

A compilação é automática a cada push na branch main. O APK é uma versão de testes (debug), não uma versão de loja.

## Tecnologia
Java WebView + Canvas 2D, Gradle 8.9, Android Gradle Plugin 8.5.2, JDK 17.
